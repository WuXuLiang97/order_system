# order_system

订单、库存、采购与成本管理系统。

## 库存核算

系统按四本账分离记录：

- 实际库存：`products.stock` / `raw_materials.stock`，只由真实出入库、生产领料、盘点和冲回动作改变，不允许负数。
- 订单占用：`inventory_reservations`，下单只占用可用成品库存，取消只释放占用。
- 订单草稿：创建订单时可先保存草稿，不占用库存；重新打开后继续编辑，提交时才生成正式订单号并建立库存占用。
- 采购单草稿：新建采购单时可先保存草稿，不生成正式采购单号，也不计入在途采购、库存和采购汇总；重新打开后可继续编辑或提交。
- 采购需求：由实际库存、订单占用、生产短缺、在途采购和安全库存实时计算，净需求可显示为负数。
- 成本流水：`stock_movements` 记录每次入库、出库、领料、完工和冲回的数量、单位成本及金额；成品移动平均成本保存在 `products.avg_cost`，原材料移动平均成本保存在 `raw_materials.avg_cost`。

启动时 `models.EnsureInventoryAccounting` 会自动创建新账表。历史负库存会归零，并写为 `legacy_shortage` 记录，后续继续计入净需求，不再进入账面库存。

## 库存台账与盘点

- `库存台账` 页面统一查询入库与库存流水，可按日期、成品/原材料、来源、方向、来源单号、批次和经办人筛选。
- 手工入库记录业务日期、成本单价、批次、来源说明和经办人；生产入库记录业务日期、生产批次、说明和经办人。
- 产品与原材料的资料编辑页库存只读，库存必须通过采购、生产、出库或盘点动作改变。
- 盘点单支持草稿、提交、取消和审核过账。提交前必须录入全部实盘数量；成品实盘数为整数，原材料支持小数。过账时重新读取最新库存，盘盈写 `stocktake_in`，盘亏写 `stocktake_out`。

## 数据分析

- 毛利 = 已发货订单收入 - 产品材料成本。
- 纯利润 = 毛利 - 对应统计周期的费用；费用按“所属月份”汇总，按月统计时扣除所选月份费用，按年统计时扣除全年费用。
- 多产品盈利排行仍按毛利排序，公共费用不强行分摊到单个产品。

## 主要接口

- `GET /api/purchase-materials/demand`：原材料净需求与建议采购量。
- `GET /api/stock-movements?item_type=raw_material&item_id=1`：库存与成本流水。

## 界面结构

- 订单、采购单：独立表单页，左侧分区导航，底部固定汇总栏。
- 产品、客户：独立页面配合标签页展示不同业务视图。
- 费用：列表页负责筛选和查看，新增与编辑进入独立表单页。
- 订单状态、回款状态、支付水单和凭证：使用小弹窗快速查看或修改。
- 订单产品：在产品行内输入名称、规格或包装进行联想选择；采购物料、产品 BOM 仍使用小型选择器弹窗。
- 新增与编辑共用同一表单模板，通过 `id` 查询参数切换模式。
- 列表页只负责筛选、查看和进入编辑器。
